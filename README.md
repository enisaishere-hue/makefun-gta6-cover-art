# Sunset Cover Studio

An offline web app that turns a photo plus a caption into multi-panel
GTA 6-style poster cover art — the bold-lettered, multi-panel look of
the Vice City posters, rendered entirely on your own machine.

## What it does

- Five panel layouts, from a single hero panel to a four-panel collage.
- Four colour grades: Vice Sunset, Neon Night, Teal Gold, and Mono Noir.
- Per-panel crop, zoom, and rotate, so any photo fits any panel.
- Bold poster lettering for the caption, styled like a game cover.
- PNG export at 1080×1080, 1080×1350, and 1920×1080.
- Fully offline: the app makes no network requests, and your photos
  never leave your machine.

## How to run it

Serve the app folder with any static server — the repo's serve script
does this on port 8080 — then open it in desktop Chrome, drop in a
photo, pick a layout and a grade, type a caption, and export the PNG.

The program at the repo root hands the app in for the bounty.
